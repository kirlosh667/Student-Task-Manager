# EduTrack — Modern Student Task & Study Manager

A sleek, responsive, and feature-packed Student Task Manager web application built with pure HTML5, CSS3, and modern JavaScript.

![EduTrack Banner](https://images.unsplash.com/photo-1434030216411-0b793f4b4173?auto=format&fit=crop&w=1200&q=80)

---

## 🌟 Features

- 📊 **Dynamic Student Dashboard**: Real-time statistics for Total, Pending, In Progress, and Completed tasks, plus an SVG progress ring.
- ⏰ **Deadline & Overdue Tracking**: Upcoming deadlines widget with countdown indicators and an alert banner for overdue assignments.
- 📝 **Full Task Management**: Add, edit, delete, inspect, and toggle tasks with priority (Low, Medium, High), due dates, and subjects.
- 📚 **Subject & Course Organization**: Add and manage custom courses with color accents and track completion rates per subject.
- 🔍 **Live Search & Multi-Filters**: Instant search (Ctrl+K), status tabs, priority filters, sorting, and Grid/List view switcher.
- ⏱️ **Focus Pomodoro Timer**: Built-in 25/5/15-minute study timer with task-linking and session statistics.
- 🌓 **Dark & Light Mode**: Seamless theme toggle persisted in browser storage.
- 💾 **100% Client-side LocalStorage**: Persistent state across sessions with JSON export and import capabilities.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

---

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser or serve with any static web server:

```bash
# Using VS Code Live Server or Python
python -m http.server 8000
```
